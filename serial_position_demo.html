MEMORY LAB / DEMO

系列位置効果

初頭効果・新近性効果と妨害課題の影響を体験する

01 / INTRODUCTION

実験の説明

15個の単語が1語ずつ2秒間表示されます。できるだけ多く覚えてください。単語の提示後，覚えているものを順序に関係なく入力します。

2種類の条件を実施します。一方は単語の提示直後に再生し，もう一方は20秒間の計算課題の後で再生します。条件の順序は参加者ごとに変わります。

各条件で単語は異なります。再生時間は60秒です。入力した単語の正誤は実験終了まで表示されません。

02 / TRIAL

画面を見て単語を覚えてください

DISTRACTOR / 20 SECONDS

計算課題

表示された2桁の数字から17を引き，正しい答えをタッチしてください。回答すると次の問題が表示されます。

FREE RECALL

覚えている単語を入力

思い出した単語を1語ずつ追加してください。順序は自由です。入力中に正誤は表示されません。

入力の確定後は「回答を終える」を押してください。60秒経つと自動的に終了します。

NEXT TRIAL

1つ目の条件が終了しました

次は別の単語リストを使います。続けて実施してください。

03 / RESULTS

実験結果

初頭部（1〜5語），中間部（6〜10語），新近部（11〜15語）の再生率を比較します。

クラス全体への結果送信

実験の終了後，正誤データを匿名で送信します。

送信するのは各条件15項目の正誤・条件順序・計算課題の集計のみです。単語の入力内容・氏名・参加者IDは送信しません。

注意：本デモは各条件1リストのため，各系列位置の成績は正答／非正答の2値です。リストの難易度や順序，練習効果も影響します。新近性効果の変化を厳密に検証するには，複数の参加者とリストを用いた条件の釣り合わせが必要です。
